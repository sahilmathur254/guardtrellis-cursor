**Native Cursor helper and local preparation**

The selected helper reads hook configuration, approved source and its ownership inventory. It writes a local control/source tree, path/hash record and one project lifecycle entry; it does not collect arbitrary project files or conversation history. The `workspaceOpen` bootstrap receives host metadata that can include workspace roots, host version and user-email metadata, validates the chosen workspace/configuration/record/source and returns a fixed path. It does not retain a raw event payload or call the SDK. Cursor's own debug logs can retain input independently.

When invoked, the prompt adapter reads a bounded event and checks only its prompt through selected local SDK signatures. Actual preview.3 native prompt execution remains unverified. Terminal preparation intentionally emits checked remaining text to stdout and fixed metadata to stderr. Optional `--open` sends accepted text through local OS/Cursor handling, without Send; other attachments/context are not sanitized. Host/provider histories, naming and other processing remain governed by their settings/terms. Local checking and Cancel do not establish no network or downstream requests.

Owned source, record paths/hashes, external-runtime marker/inventory and host-captured streams remain locally until reviewed removal. Runtime setup may contact registries for locked dependencies. The local tools add no publisher account system, hosted scanner, telemetry or automatic support upload. Ownership hashes are integrity metadata, not signatures or a hostile-writer guarantee. Separate profiles do not hide all home hooks/caches or override managed policy.

Voluntary support email is received by the publisher and communications providers and retained as needed for the request/follow-up, without a fixed deletion schedule or blanket no-retention promise. Access/correction/deletion requests use the published contact, subject to applicable requirements/provider backup limitations. No raw sensitive material is needed for routine metadata-only support.
